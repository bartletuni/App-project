💡 What:
Added `aria-hidden="true"` to the decorative `<Eye>` and `<EyeOff>` icons inside the password visibility toggle buttons in both `src/app/login/page.tsx` and `src/app/settings/page.tsx`.

🎯 Why:
The parent `<button>` element already handles accessibility by providing an explicit `aria-label` ("Show password" or "Hide password"). Leaving the child SVG icons visible to the accessibility tree causes screen readers to redundantly announce the icon's generic name in addition to the button's label, creating a confusing and noisy experience.

♿ Accessibility:
Improved screen reader clarity by explicitly hiding purely decorative icons when the parent interactive element already provides an accessible name.
