💡 **What**: Added visual feedback to the submit button when it is disabled due to missing file, and added `aria-hidden="true"` to decorative icons across forms for better screen reader accessibility.
🎯 **Why**: The submit button allows clicking when missing a file which gives an abrupt error instead of preventing the click altogether. A tooltip guides the user to the correct action. Also, the decorative icons lacked proper aria tags.
♿ **Accessibility**: Enhanced the UX by preventing invalid submission attempts, explicitly guiding users to required fields, and silencing screen readers on purely visual icons (`ArrowUp`, `Plus`).
